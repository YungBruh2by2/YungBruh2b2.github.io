# Skyrim Interactive Web Map

A Skyrim-themed web page built with HTML5 and CSS3. This project features a centered, responsive layout displaying an interactive list of iconic Skyrim holds/cities alongside a map of the province.

## Features

- **Thematic Styling:** Custom Skyrim-inspired aesthetics featuring aged parchment background textures, `darkred` lore-friendly typography, and multi-layered black text shadows.
- **Responsive Layout:** Centered content containers utilizing CSS block/inline-block formatting and flexible image sizing (`max-width` / dynamic scaling).
- **Interactive Navigation:** Direct external wiki links for major Skyrim locations:
  - Markarth
  - Falkreath
  - Riften
  - Whiterun
  - Windhelm
  - Winterhold
  - Dawnstar
  - Morthal
  - Solitude

## Getting Started

1. Clone or download this repository to your local machine.
2. Open `index.html` in any standard modern browser (Chrome, Edge, Firefox, Safari).

## Technologies Used

- **HTML5** – Page structure and link anchors
- **CSS3** – Custom layout, styling, text-shadows, and background management
- **Sublime Text** – Primary code editor
